# 拉筋計時器 Stretch Timer

手機用的兩階段循環計時器，單一 HTML 檔，可直接放在 GitHub Pages 上執行。
畫面分為 **Prepare（準備）** 與 **Cycle Run（拉筋）** 兩個階段，依設定的次數循環，並同步倒數整趟總時間。

目前版本：**v1.3.0**（版號顯示在畫面底部工具列中央，以及設定頁最下方）

---

## 功能

- 兩階段循環：Prepare → Cycle Run → Prepare → …，到達設定輪數後停在「完成」畫面
- 階段提示音：Prepare 結束時兩短音（代表 Cycle Run 開始），Cycle Run 結束時一長音
- 語音播報：每輪 Cycle Run 開始時唸出「Cycle 1 start」「Cycle 2 start」…
- 倒數提示音：每個階段最後 3 秒嗶、嗶、嗶（可關閉）
- 提示音量：0–100% 可調，同時套用到提示音、倒數音與語音播報
- 五種提示音：嗶聲、鈴聲、木魚、電子錶、靜音，設定頁中點選即可試聽
- 總時間：依（Prepare + Cycle）× 重複次數計算，開始後同步倒數
- 螢幕常亮：優先使用 Wake Lock API，不支援時自動退回無聲循環影片備援，避免計時中息屏
- 防止雙擊放大：整個計時畫面不會因連點而縮放
- 設定存在瀏覽器本機（localStorage），下次開啟沿用

## 操作方式

計時畫面（不含底部工具列）的點擊規則：

| 動作 | 效果 |
| --- | --- |
| 點一下 | 開始計時；暫停中則繼續；完成後則重新開始 |
| 點兩下 | 暫停 |
| 點三下 | 清空輪數計數，回到 Prepare 等待開始 |

底部工具列不在點擊範圍內，點它不會開始或暫停計時。
單擊需等約 0.35 秒，確認不是雙擊或三擊後才動作，因此開始時會有些微延遲。

## 設定

| 項目 | 預設 | 範圍 | 說明 |
| --- | --- | --- | --- |
| Prepare | 5 秒 | 1–600 | 準備秒數 |
| Cycle Run | 30 秒 | 1–3600 | 拉筋秒數 |
| 重複次數 | 10 輪 | 0–99 | 設 0 為無限循環，總時間顯示 ∞ |
| 提示音 | 嗶聲 | 五選一 | 選靜音時，音量與下列兩個開關一併停用 |
| 提示音量 | 80% | 0–100% | 每 5% 一格，放開滑桿會試聽一聲 |
| 倒數提示音 | 開 | 開／關 | 每階段最後 3 秒 |
| 語音播報 | 開 | 開／關 | Cycle N start |

計時中開啟設定會自動暫停。按「取消」恢復計時，按「儲存」套用新設定並重置計時。
加減按鈕可長按連續調整。

## 部署到 GitHub Pages

1. 建立 repository，把 `index.html` 放在根目錄（或 `docs/` 資料夾）。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)` 或 `/docs`。
3. 等待部署完成後，以手機開啟 `https://<帳號>.github.io/<repo>/`。
4. 建議用 Safari 或 Chrome 的「加入主畫面」，以全螢幕方式使用。

更新後如果畫面版號沒有變，代表手機讀到的是快取，重新整理即可。

## 瀏覽器需求與已知限制

- 螢幕常亮需要 HTTPS 環境（GitHub Pages 符合）。工具列右側顯示狀態：綠點為 Wake Lock 生效，黃點為影片備援生效，灰點為兩者皆未啟動，紅點為瀏覽器不支援。點一下該處可重新嘗試。
- 低耗電模式（省電模式）會阻擋影片自動播放，備援機制在此模式下可能失效。
- iPhone 側邊靜音開關打開時，網頁的提示音通常會被靜音。App 會嘗試以 AudioSession playback 模式避開，但此 API 僅部分 Safari 版本支援，仍建議關閉靜音開關並調高媒體音量。
- 語音播報使用瀏覽器內建的 Web Speech API，實際發音會因裝置安裝的語音而異。設定頁有「試聽語音」按鈕可確認裝置是否正常。
- 提示音為程式即時合成，不需要任何外部音檔。

## 檔案結構

```
index.html              # 完整的 App，含 HTML、CSS、JavaScript
manifest.webmanifest    # 主畫面安裝設定（名稱、圖示、全螢幕）
apple-touch-icon.png    # iOS 主畫面圖示 180×180
icon-192.png            # 圖示 192×192
icon-512.png            # 圖示 512×512
README.md               # 本說明文件
```

以上檔案全部放在 repository 根目錄，路徑為相對路徑，放在子資料夾也能運作。
